             Back to top      op 0   <<< transform finished, opacity did not

    ~3500ms  Back to top      op 0   <<< still 0; not a slow tween

  Inline styles at rest showed the cause was the tween's own end value:
    CarterPCs      style="... transform: translate(0px, 0px); opacity: 1;"  transition: all
    Independent... style="... transform: translate(0px, 0px); opacity: 1;"  transition: all
    Back to top    style="... transform: translate(0px, 0px); opacity: 0;"  transition: opacity 0.15s

  The only element that differed was the only one carrying a CSS
  transition on opacity. gsap.from() records its END value when the
  tween first RENDERS; immediateRender had already written opacity:0 at
  timeline-creation time, the CSS transition then settled the element at
  0, and when the ScrollTrigger fired GSAP read 0 back as the natural
  value and animated 0 -> 0.

  Fixed twice over: the tween is now fromTo with both ends stated, and
  the link's hover transitions colour instead of opacity.

  `color(srgb 0.960784 0.960784 0.952941 / 0.62)` — and the probe's colour
