# CarterPCs Portfolio Concept — Design Specification

## Main Reference

Primary visual and motion reference:

https://youtu.be/tf_yi6DtDOQ?si=jwLbQWsOALTMMg00

The reference is used for inspiration regarding:

- layout
- animation quality
- visual pacing
- typography
- scrolling behavior
- cinematic presentation
- transitions

The final project must remain original.

## Visual Direction

The design should feel:

- premium
- cinematic
- experimental
- modern
- editorial
- bold
- minimal
- interactive

## Typography

Use:

- oversized headlines
- strong sans-serif typography
- large section numbering
- high contrast between headline and body text
- minimal body copy

Example:

CARTERPCs

TECH.
HARDWARE.
CULTURE.

## Layout

Use:

- full-screen sections
- asymmetric compositions
- large imagery
- generous whitespace
- overlapping typography
- layered content
- horizontal scrolling where appropriate

Avoid repetitive card grids.

## Motion Design

Use:

- scroll-triggered reveals
- text masking
- kinetic typography
- image scaling
- parallax
- section transitions
- horizontal scroll sequences
- magnetic buttons
- hover distortion where appropriate
- custom cursor interactions
- subtle depth effects

Motion should feel smooth and intentional.

Avoid animation for animation's sake.

## Color Direction

Primary:

- black
- off-white
- charcoal
- soft gray

Accent:

- subtle electric blue or another restrained tech accent

Avoid excessive RGB.

## Hardware Presentation

Hardware should feel cinematic and premium.

Potential visual sequences:

- exploded PC
- GPU close-up
- motherboard details
- CPU
- cooling
- RAM
- storage
- complete PC build

## Mobile Design

Mobile must not simply shrink the desktop layout.

Interactions and animation should adapt intelligently for:

- touch
- smaller screens
- reduced motion
- performance
